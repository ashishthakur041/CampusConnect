🎓 CampusConnect

Smart Campus Navigator & Lost Item Tracker

CampusConnect is a simple, responsive web project designed to help students explore campus information and access useful campus-related features.

✨ Features

- 🗺️ Campus navigation interface
- 🔍 Lost and Found interface
- 📢 Campus notice board
- 📱 Responsive user interface
- 🎨 Clean and user-friendly design

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

🌐 Live Demo

"Visit CampusConnect" (https://ashishthakur041.github.io/CampusConnect/)

🚀 How to Run Locally

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open "index.html" in your browser, or use the Live Server extension.

🎯 Project Objective

The goal of CampusConnect is to provide students with a simple interface for exploring campus-related information and accessing lost-and-found features.
